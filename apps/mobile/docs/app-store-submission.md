# App Store submission checklist

Everything App Review looks at that can be settled in the repo is already in
place. This page lists what is **done in code** and what only **you** can do
(accounts, credentials, store listing). Pair it with
[`testflight.md`](./testflight.md), which covers the build and upload commands.

## Already in the repo

| Requirement | Where |
|---|---|
| Real app icon (1024px, opaque, no alpha) and splash | `assets/images/`, regenerated by `npm run build:mobile-icons` from the brand reticle |
| In-app account deletion (guideline 5.1.1(v)) | Account tab → *Request account deletion* → `POST /api/users/me/deletion-request` |
| Privacy manifest and required-reason API declarations | `app.json` → `ios.privacyManifests` |
| Export-compliance answer | `app.json` → `ios.config.usesNonExemptEncryption: false` (HTTPS only, no custom crypto) |
| Camera and photo usage strings | `app.json` → `ios.infoPlist` and the `expo-image-picker` plugin |
| Microphone not requested | `expo-image-picker` `microphonePermission: false`; Android `RECORD_AUDIO` blocked |
| Links to privacy policy, terms and support | Account tab (opens the web pages) |
| Push notifications | `expo-notifications`; token registered at `/api/push/expo-token` |

## You need to do

1. **Create the EAS project id.** Run `eas init` in `apps/mobile`. It writes
   `extra.eas.projectId` into `app.json`. Until then the app runs but cannot
   get a push token (it logs a warning and carries on).
2. **Upload an APNs key for push.** `eas credentials` → iOS → Push Notifications.
   Without it, notifications reach Android only.
3. **Fill the ASC fields in `eas.json`** and place the `.p8` key
   (see `testflight.md` §1).
4. **Set the EAS environment variables** for production (see `testflight.md` §2).
5. **Apply migration 304** (`expo_push_tokens`, `account_deletion_requests`) to
   the production database before shipping a build that registers push tokens.
6. **Create a reviewer account.** App Review must be able to sign in.
   Create a user on a demo tenant with the modules enabled (incidents, BBS,
   inspections, confined spaces, hot work) and seed at least one open permit so
   the Permits tab is not empty. Put the credentials in *App Review
   Information*.
7. **Take screenshots.** 6.9" iPhone (1320×2868) and 13" iPad
   (2064×2752) are required because the app declares `supportsTablet: true`.
   Suggested set: Home hub, Permits board, confined-space reading entry,
   incident report, inspection run.
8. **Fill in the listing:** name, subtitle, description, keywords, support URL
   (`/support`), privacy policy URL (`/privacy`), marketing URL, age rating,
   category (Business or Productivity).

## App Privacy ("nutrition label") answers

These match `ios.privacyManifests`. Nothing is used for tracking.

| Data type | Collected | Linked to user | Purpose |
|---|---|---|---|
| Email address | Yes | Yes | App functionality (sign-in) |
| User ID | Yes | Yes | App functionality |
| Device ID (push token) | Yes | Yes | App functionality (notifications) |
| Photos | Yes | Yes | App functionality (equipment and isolation-point photos) |
| Other user content | Yes | Yes | App functionality (incident, inspection, observation text) |

Tracking: **No.** Third-party advertising: **No.**

## Notes for App Review (paste into the review notes)

> Soteria FIELD is a workplace-safety app for industrial employers. Sign in
> with the demo account below. The Home tab lists the modules enabled for the
> demo workspace. The Permits tab shows open confined-space and hot-work
> permits; open one to record an atmospheric reading. Account → *Request
> account deletion* starts account deletion. Accounts are created by an
> employer administrator, so there is no self-registration screen.
>
> The camera is used only to attach photos of equipment to safety records.

## Known limits of this release

- Creating a permit, signing a toolbox talk, fire-watch sign-on, and photo or
  signature inspection items are web-only. The inspection run screen says so
  and blocks submission when such an item is required.
- Push delivery and the camera can only be verified on a physical device; see
  `smoke-test.md`.
